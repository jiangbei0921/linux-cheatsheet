# Linux 命令速查 · 技术文档

> 版本：v1.0 ｜ 日期：2026-08-01 ｜ 状态：已实现（Craft 模式落地）

## 1. 概述

**Linux 命令速查** 是一款面向中文用户的免费命令行查询工具。其目标是降低命令的记忆与理解门槛：用户可用中文关键词（如"删除文件""查看日志""端口"）或命令名（如 `ls`、`top`）快速检索到命令，并获得中文说明、常用参数示例、典型场景、易错警告与命令对比。

产品定位为 **"初学者友好的命令学习参考"**，而非又一个速查表。其差异化在于：
- 本地毫秒级搜索，无需联网；
- 讲解式内容（易错警告 `pitfalls` + 命令对比 `compare`），帮助"读懂 AI 生成的命令"；
- 频率/难度双维度标注，初学者默认聚焦高频入门命令。

## 3. 功能需求

1. 内置全部常用 Linux 命令清单（518 条，含 Vim 133 条），**每条含中文说明、常用参数示例、典型场景**。
2. 支持**中文关键词 + 命令名**搜索（包含匹配，忽略大小写）。
3. 支持**分类导航**（文件操作、进程管理、版本控制等）。
4. 命令详情展示：说明、频率/难度徽章、使用案例（可一键复制）、易错警告、命令对比、关键词标签。
5. 纯本地或轻量部署，无付费、无使用门槛。

## 4. 非功能需求

- **零依赖、零构建**：原生 HTML/CSS/JS，双击 `index.html` 即用。
- **中文界面**：全中文文案与说明。
- **搜索响应**：百条级数据客户端过滤耗时 < 1ms。
- **可维护性**：命令数据外置为 `data/commands.json` 与 `data/commands.js`，由 `tools/build_commands.py` 统一生成。
- **跨平台**：桌面浏览器、移动端浏览器均可使用。

## 5. 技术选型

| 维度 | 选型 | 理由 |
|------|------|------|
| 形态 | 纯前端静态单页应用 | 符合"免费/轻量/纯本地/无门槛"硬约束 |
| 语言 | 原生 HTML + CSS + JavaScript（ES5 风格 IIFE） | 零依赖、零构建，双击 `file://` 即用 |
| 数据 | 外置 JSON，并额外生成 `commands.js`（`window.COMMAND_DATA`） | `file://` 下 `fetch` 受 CORS 限制，用 `<script>` 注入全局变量规避 |
| 搜索 | 客户端 `Array.filter` + `String.indexOf` 包含匹配 | 百条级无需防抖/索引，足够快 |
| 部署 | GitHub Pages / 腾讯云 EdgeOne Pages / 本地静态托管 | 任意静态服务即可 |

**为何不选 Python 服务 / 桌面应用**：前者需运行环境、违背"纯本地一键用"，后者分发成本高，均不符合轻量无门槛约束。

## 6. 架构

```
浏览器
 └─ index.html  (页面骨架 + 加载脚本)
     ├─ styles.css  (浅色中文界面)
     ├─ data/commands.js  (window.COMMAND_DATA: {categories, commands})
     └─ app.js  (加载数据 → 构建分类索引 → 渲染侧栏/列表/详情 → 搜索/复制交互)
```

数据流：`commands.js` 注入全局对象 → `app.js` 读取并构建 `catMap`（分类索引）→ 用户搜索/点选 → `filtered()` 过滤 → 渲染列表或详情。

## 7. 数据模型

命令对象字段（位于 `data/commands.json` 的 `commands` 数组）：

```json
{
  "name": "rm",
  "category": "file",
  "description": "删除文件或目录",
  "keywords": ["删除文件", "删除目录", "移除", "rm"],
  "examples": [
    {"cmd": "rm file.txt", "desc": "删除单个文件"},
    {"cmd": "rm -rf dir", "desc": "递归强制删除目录（危险）"}
  ],
  "frequency": "高",
  "difficulty": "入门",
  "pitfalls": "rm -rf / 或 rm -rf ~ 会销毁系统/家目录数据，务必先确认路径",
  "compare": "rm 删文件；rmdir 仅删空目录；mv 到 /tmp 可作软删除"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 命令名（Git 含 `git ` 前缀，如 `git reset`） |
| `category` | string | 分类 ID，对应 `categories` 中的 `id` |
| `description` | string | 中文一句话说明 |
| `keywords` | string[] | 中文检索词 + 命令名，供搜索匹配 |
| `examples` | {cmd, desc}[] | 使用案例；`cmd` 可原样复制，`desc` 讲清含义 |
| `frequency` | 高/中/低 | 使用频率维度 |
| `difficulty` | 入门/日常/进阶 | 学习难度维度 |
| `pitfalls` | string? | 易错警告（可空） |
| `compare` | string? | 命令对比（可空） |

## 9. 频率/难度标注体系

对每条命令独立标注两个维度：

- **使用频率（frequency）**：`高`（日常高频，如 `ls`/`top`）/ `中` / `低`（如 `chattr`/`sysctl`）。
- **学习难度（difficulty）**：`入门`（首次接触即可用）/ `日常`（需理解参数组合）/ `进阶`（涉及原理或风险，如 `iptables`/`strace`）。

标注依据综合了公开命令使用统计（webminal.org 真实命令统计、Stack Overflow 2025、各发行版/中文技术社区文档）与教学路径框架交叉验证。两者相互独立：例如 `top` 频率高但属日常难度，`rsync` 频率低但属进阶难度。

界面中频率/难度以彩色徽章呈现，初学者可通过"全部/高频"过滤快速聚焦。

## 10. 搜索算法

- 输入 `q` 经 `trim` 与 `toLowerCase` 归一化。
- 每条命令构造匹配串 `name + description + keywords.join(' ')`（小写）。
- 过滤规则：`q` 为空返回全部分组命令；否则要求匹配串 `indexOf(q) !== -1`（包含匹配）。
- 分组/分类过滤：`group`（all/linux）与 `cat`（分类 ID）两级叠加。
- 命中关键词在列表名称与说明中以 `<mark>` 高亮。
- 复杂度 O(N·L)，N≤518、L 为短串，耗时 < 1ms，无需防抖。

## 11. 界面与交互

- **顶栏**：标题 + 中文搜索框 + 分组筛选（Linux）。
- **侧栏**：按 Linux 分组列出分类，每项显示命令数；点击切换分类。
- **内容区**：
  - 列表态：卡片网格，每张卡显示命令名、中文说明、分类、频率/难度徽章。
  - 详情态：点击卡片进入；展示说明、徽章、使用案例（每条带"复制"按钮）、易错警告（橙框）、命令对比（蓝框）、关键词标签；"返回列表"回到列表。
- **复制**：`navigator.clipboard.writeText`，失败回退到 `textarea + execCommand`；按钮显示"已复制"反馈。
- **响应式**：窄屏（<760px）侧栏转为顶部，单栏布局。

## 16. 新增模块：熟练度检测、AI 模拟面试、指令查询与指令生成（2026-08-02）

在保留原「命令速查」全部功能的基础上，顶部新增 Tab 导航（共 5 个：`命令速查 / 熟练度检测 / 模拟面试 / 指令查询 / 指令生成`），其中熟练度检测与模拟面试按 Linux 分组，指令查询与指令生成为纯本地离线模块，复用同一份 518 条命令数据作为内容引擎。

### 16.1 指令熟练度检测（纯前端，A+B 双模式）
- **入口**：Tab → 熟练度检测 → 选 Linux。
- **A 自测清单**：列出该组全部命令，逐条自评 `已掌握 / 模糊 / 不会`，实时计算掌握度（已掌握 100% · 模糊 50% · 不会 0%），按分类「全标已掌握 / 不会」快速自评，一键生成掌握度地图（总掌握度 + 各分类进度条 + 薄弱命令清单）。
- **B 实战任务**：给出中文场景，由用户手写完整命令，按「核心命令令牌 + 必要参数令牌」即时校验，逐题反馈并给出正确率与薄弱点报告；每轮随机 10 题，可提前结束出报告。
- **约束**：纯本地运行，无网络依赖、无 API Key。

### 16.2 AI 模拟面试（浏览器直连 LLM）
- **入口**：Tab → 模拟面试 → 选 Linux；首次需点击右上角 ⚙ 配置 API Key。
- **架构**：纯静态 SPA，不搭建后端。Key 由用户在设置弹窗中自带，仅存于浏览器本地（`localStorage`），只发往所选服务商。
- **支持的浏览器直连服务商（11 家）**：OpenAI、Anthropic(Claude)、Google Gemini、OpenRouter(聚合网关)、DeepSeek、通义千问、智谱 GLM、Kimi(Moonshot)、Groq、Mistral、Together（OpenAI 兼容 / Gemini 原生 / Anthropic 原生三种协议，均支持 SSE 流式）。
- **对话**：`fetch` + `ReadableStream` 解析 SSE 流式输出（含 90 秒超时保护）；system 角色设定"资深面试官"，按所选方向循序渐进追问。
- **报告**：点击「结束并生成报告」，模型基于对话输出技术深度评分 / 知识盲区 / 表达建议。

### 16.3 指令查询与指令生成（纯前端，离线）
- **指令查询**：输入一条完整命令（如 `find . -name "*.log" -delete`、`chmod 755 app.sh`），自动按空白与引号分词，逐步前缀匹配识别多词命令名，并对组合短选项（如 `-la`）做选项级匹配，结合 `examples` 解释每个参数/选项的作用；组内无命中时给出模糊建议卡片。
- **指令生成**：用一句话描述任务（如"删除当前目录所有 .log 文件""找出占用空间最大的前 10 个目录"），基于 `TASK_INTENTS` 意图词表 + 中文二元组（CJK bigram）重叠 + 关键词/命令名/分类/示例英文令牌等多信号加权打分，返回至多 6 条最相关命令及可直接执行的示例（含参数填充），并支持「查看含义」跳转至指令查询。
- **约束**：纯本地运行，无需联网或 API Key。
